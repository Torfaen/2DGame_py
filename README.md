## 🚀 如何启动游戏
启动方法1：
1. 进入 `2dgame/dist` 文件夹
2. 双击 `BNB_2Dgame.exe` 文件即可启动游戏

启动方法2：
1. 在项目根目录下双击 `启动游戏.bat` 文件即可启动游戏

## 📋 游戏规则

### 基本规则
- 这是一款双人对战游戏，两名玩家在地图上进行对战
- 玩家可以通过放置炸弹来炸毁障碍物和击败对手
- 炸弹会在放置后一段时间爆炸，爆炸范围呈十字形扩散
- 被炸弹爆炸波及的玩家会死亡

### 游戏模式
- **一条命模式（ONE_LIFE）**：玩家只有一条生命，被炸到即死亡
- 最后存活的玩家获胜

### 道具系统
破坏障碍物方块后，有概率掉落以下道具：
- **加速道具**：增加移动速度
- **最大速度道具**：提升最大移动速度上限
- **炸弹数量增加道具**：增加可同时放置的炸弹数量
- **炸弹威力增加道具**：增加炸弹的爆炸范围

### 地图元素
- **不可摧毁的墙体**：无法被炸弹破坏，用于阻挡玩家和爆炸
- **可摧毁的障碍物**：可以被炸弹炸毁，炸毁后可能掉落道具
- **空地**：玩家可以自由移动的区域

### 获胜条件
- 在一条命模式下，击败所有对手即可获胜
